# Public Repository Scope

This repository is intentionally limited to portfolio-facing material.

## Included

- High-level project description
- Architecture diagram
- Sanitized automation workflow image
- Portfolio case-study PDF
- Selected aggregate metrics and methodology descriptions

## Intentionally excluded

- Full source code and Jupyter notebooks
- Complete data files and analytical exports
- Power BI PBIX file
- DAX implementation library
- n8n workflow JSON
- API endpoints used for private execution
- Telegram tokens, credentials, chat identifiers, or authentication material
- Pickle, Parquet, checkpoint, and intermediate-state files

The complete implementation is maintained privately by the project owner and may be demonstrated selectively for interview or technical-review purposes.
